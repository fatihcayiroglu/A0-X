# P180: 128×128 parameter-bound full-frame RTL oracles

P178 established pixel-accurate host versus independent P102 reference results at 64×32, 32×64 and 64×64. P180 adds an **independent, simulation-only** workflow for **128×64, 64×128 and 128×128**, exercising the current scaled core's specified 128-coordinate dimension ceiling. Existing physical and simulation ratchets remain unchanged.

## Strict evidence contract

- Compile the real `a0_p172_scaled_programmed_fragment_p102_tb.sv` and unchanged synthesizeable design with Icarus for each geometry. Execute each shape under a finite **240-second** timeout; no skipped or downgraded tests.
- Require exactly one `P172_SCALED_PROGRAMMED_P102_PASS` and one `P173_DRAW_TIMING_PASS` marker per shape; verify clears=3, draws=2, 256 texture writes, ≥8 rejected host requests, one busy denial and one missing texture fault. Observe **5*W*H** exact reference framebuffer reads and **2*W*H** covered fragments per shape.
- New P180 total: **163,840** framebuffer observations and **65,536** shaded fragments over three shapes. The 128×128 geometry alone requires **81,920** independent framebuffer reads and **32,768** shaded fragments.
- Assert measured first/second shader completion times under the original P174 budgets `52*N+2 / 35*N+2` and accelerated P175 budgets `51*N+2 / 34*N+2`. Both transposed 128×64 and 64×128 shapes must produce equal measured times, strictly below 128×128 times.
- Upload full compile and RTL simulation logs even on failure. Any timeout, comparison mismatch, unexpected geometry, missing marker, invalid cycle count or artifact failure blocks merge.

## Interpretation and safeguards

128×128 uses the existing core's highest allowed frame **dimension**, not proof of larger physical FPGA fit. P177 previously proved actual 32×32 ECP5 physical route (35.04 MHz, 77 pins, five BRAM, 72 DSP); P179 separately evaluates a 32×64 physical route. P180 must not alter those physical gates or the prior P172/P173/P178 simulations. The RTL test is **not** display timing, VRAM throughput, PCIe operation, game FPS or RTX 6090-class GPU readiness.
